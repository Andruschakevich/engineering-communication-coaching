# Curriculum

The eight-session curriculum is the learning path for the Engineering Communication Coaching Program. Each session combines reflection, a focused concept, realistic practice, feedback, and a small real-world experiment.

> **Coach navigation:** For preparation and the full engagement lifecycle, start with the [main README](../README.md). For delivery instructions, use the [Facilitator Guide](../facilitator-guide/README.md).

## How to use the curriculum

1. Start from the participant's agreed development goals and current needs.
2. Follow the reference sequence, but adapt emphasis and pacing where useful.
3. Keep theory concise; spend more time on practice and reflection.
4. Use examples that are realistic but sanitized and appropriate to share.
5. End every session with one observable behavior experiment.
6. Review progress around session 4 and after session 8.
7. Assign only the Must do items by default; offer Nice to do extensions when useful and realistic.
