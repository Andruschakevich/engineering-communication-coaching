# Session 4 — Structured Communication

**Objectives:** State the point early, adapt detail to audience, separate facts from assumptions, and explain technical issues concisely.

## Frameworks
- **BLUF:** Bottom Line Up Front—lead with the conclusion or request, then give necessary context.
- **PREP:** Point, Reason, Example, Point.
- **Problem → Impact → Options → Recommendation:** problem/context, business or engineering impact, options/trade-offs, recommendation and decision needed.

## Exercise
Explain the same technical issue to a senior engineer (3 min, technical trade-offs), a product manager (2 min, user and delivery impact), and an executive (1 min, business impact, risk, decision).

Record each explanation. Was the point clear in the first 20 seconds? Was every detail necessary?

## Homework
Prepare a current technical issue using Problem–Impact–Options–Recommendation. Ask a colleague from another role whether it was clear.
