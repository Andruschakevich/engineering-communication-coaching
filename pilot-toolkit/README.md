# Pilot Toolkit

Use this folder to launch and run a coaching engagement. It contains the practical documents a coach needs before, during, and after the sessions.

> New coach? Start with the [repository README](../README.md), then follow the [end-to-end coaching journey](../README.md#the-end-to-end-coaching-journey).

## Recommended workflow

1. **Align:** agree on purpose, roles, development scope, manager involvement, and privacy boundaries.
2. **Prepare:** review the kick-off presentation, initial meeting script, and coaching agreement.
3. **Kick off:** obtain recording/transcription consent before any recording; explain the program; hear the participant's expectations; agree schedule and next steps.
4. **Assess:** collect participant self-assessment and appropriate manager observations. Use AI-assisted communication review only with approved tools and permitted data.
5. **Set goals:** choose 2–3 participant-owned, observable development goals.
6. **Deliver:** run the eight-session curriculum and record only the minimum necessary progress notes in an approved private location.
7. **Review:** compare evidence, gather participant feedback, and create a 90-day continuation plan.
8. **Improve:** capture anonymized lessons for the reusable framework, never identifiable participant details.

## Important boundaries

- Participation should be voluntary and informed. The participant can raise concerns or decline recording without being penalized.
- Coaching is not an investigation, therapy, disciplinary process, or replacement for manager accountability.
- Agree in advance what high-level progress information may be shared with the manager/sponsor.
- Keep participant-specific notes, assessments, recordings, and transcripts outside this reusable repository in an approved access-controlled location.
- Do not upload raw Slack/Teams exports, private messages, names, customer data, or identifiable incident narratives here.
- Before using AI with workplace communications, confirm company policy, tool approval, provider data handling, and applicable requirements.
- AI-generated assessments are fallible inputs, not objective verdicts. Review the summary with the participant and disclose evidence limitations.
