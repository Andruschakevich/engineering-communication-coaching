# Communication Rewrite Challenge

Rewrite each message to preserve the concern while removing contempt, blame, sarcasm, or unnecessary aggression.

| Original | Professional alternative |
|---|---|
| "Did you even test this?" | "I found a failure in this path. What tests were run, and can we review coverage?" |
| "This makes no sense." | "I may be missing something. Can you walk me through the reasoning?" |
| "As I already said..." | "Let me restate the key point and clarify what may have been missed." |
| "That's a stupid idea." | "I see a risk with this approach. The main concern is..." |
| "You always break this." | "This area has had several regressions. Let's identify the common cause." |
| "Just read the documentation." | "The documentation covers this; I can point you to the relevant section." |
| "Not my problem." | "I don't own this area, but I can help identify the right owner." |
| "Obviously..." | "The key point is..." |
| "You don't understand the system." | "There may be missing context. Let me explain how this part works." |
| "Whatever, do it your way." | "I disagree for these reasons. If we choose this option, let's document the risks." |

## Self-review
Is the point clear? Did I remove judgment about the person? Did I state evidence? Did I offer a question, option, or next step? Would I be comfortable reading this aloud in a team meeting?
