# Program Improvements

Prioritize changes based on pilot evidence, participant feedback, and facilitator experience.

## Backlog
- Facilitator guide with sample language and debrief prompts.
- Manager briefing and stakeholder feedback guide.
- Participant workbook.
- Async written communication module for Slack, Teams, email, and design documents.
- Adaptations for seniority levels and cultural contexts.
- Repeatable 30/60/90-day follow-up protocol.

## Pilot review questions
Which exercises created useful change? Was the theory/practice balance right? Were homework tasks achievable? Were confidentiality boundaries clear? Did managers receive useful progress information without unnecessary private detail? Which measures were meaningful?
